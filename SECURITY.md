# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for a security vulnerability.

Instead, email **kunj@printdeed.com** with:

- A description of the issue and its potential impact.
- Steps to reproduce (a minimal capture file or code snippet if applicable).
- Any suggested fix, if you have one.

You should get an acknowledgment within a few days. Once a fix is confirmed, we'll coordinate on disclosure timing before any public write-up.

## Scope

This covers the Python package (`revolt_ble_toolkit`) and its CLI/GUI/live-client entry points. The companion Dart package under [`flutter_sdk/`](flutter_sdk/) is a separate package with its own release cycle — please still report through the same email if you find an issue there.
